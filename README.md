# DevMindShell

A terminal shell for [DevMind](https://github.com/pkailas/DevMind) that connects to `DevMind.McpServer` via the MCP stdio transport, streams responses from a locally hosted LLM (Gemma 4 31B via llama-server), and surfaces the full DevMind tool suite — file reads, patch application, shell execution, search, and memory — as a Ink/React terminal UI running in any Node 20+ terminal.
